# lt-css-library

A small, reusable CSS library. Every class starts with `lt-`. Colors and spacing are CSS variables (`--lt-*`), so they can be themed.

## Install

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Leandro-K/lt-css-library@v1.0.0/lt.css">
```

## Classes

| Group | Classes |
|---|---|
| Page & layout | `lt-page`, `lt-container`, `lt-row`, `lt-grid`, `lt-scroll-x` |
| Text | `lt-h1`, `lt-h2`, `lt-muted`, `lt-small`, `lt-strong`, `lt-block`, `lt-text-center` |
| Spacing | `lt-m-0`, `lt-mb-4`, `lt-mb-5`, `lt-mt-5` |
| Card | `lt-card` |
| Forms | `lt-field`, `lt-label`, `lt-field-row`, `lt-input`, `lt-input--invalid`, `lt-field-msg` |
| Buttons | `lt-btn` + `lt-btn--primary` / `--secondary` / `--danger`, `lt-btn--sm` |
| Table | `lt-table` |
| Badges | `lt-badge` + `lt-badge--success` / `--warning` / `--danger` |
| Tabs | `lt-tabs`, `lt-tab`, `lt-tab--active`, `lt-tab-panel` |
| Stats | `lt-stat`, `lt-stat--danger`, `lt-stat-label`, `lt-stat-value` |
